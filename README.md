# morphe_curated_settings
An opinionated preference file to be used with Morphe patched applications.

# Installation
- Open YouTube Morphe.
- Go to Settings > Morphe > Settings.
- Tap on Miscellaneous.
- Tap on Import / Export.
- Tap on Import from file and import [morphe_curated_settings.txt](https://github.com/LinuxGuy-cyber/morphe_curated_settings/blob/main/morphe_curated_settings.txt)
- Click Save.
- A popup to restart the app should appear. Click Restart. Or restart the app anyway.
- Enjoy!
